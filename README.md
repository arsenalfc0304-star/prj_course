# Проект prj_course

## Описание:

Проект prj_course - это приложение на Python, реализующее следующие функции:
    *функция для страницы «Главная»*,
    *функционал сервиса «Простой поиск»*,
    *функционал отчета «Траты по категории»*.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:arsenalfc0304-star/prj_course.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:
для запуска приложения выполните команду *python main.py*

### Поддерживаемые типы файлов для считывания транзакций:
*EXCEL*

### модуль *views.py*:
содержит главную функцию для генерации JSON-ответов.

### модуль *utils.py*:
содержит вспомогательные функции, необходимые для работы функции страницы «Главная».

### модуль *services.py*:
содержит функцию сервиса «Простой поиск».

### модуль *reports.py*:
содержит функцию сервиса «Траты по категории».

## Тестирование:
Для тестирования выполните в командной строке команду *pytest*.
