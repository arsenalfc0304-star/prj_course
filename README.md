# Проект prj

## Описание:

Проект prj - это приложение на Python для реализации виджета банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:arsenalfc0304-star/prj.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:
для запуска цикла выборки данных выполните команду *python main.py*

### Поддерживаемые типы файлов для считывания транзакций:
*JSON*, *CSV*, *EXCEL*

### модуль *generators.py*:
модуль содержит генераторы, реализующие функции для работы с массивами транзакций
и позволяющие быстро и удобно находить нужную информацию о транзакциях и проводить анализ данных.

### модуль *decorators.py*:
модуль автоматически логирует начало и конец выполнения функции, а также ее результаты или возникшие ошибки,
Логи могут записываться в файл или в консоль.

## Тестирование:
Для тестирования выполните в командной строке команду *pytest*.
реализованы модули:
*test_masks.py*,
*test_widget.py*,
*test_processing.py*,
*test_generators.py*,
*test_decorators.py*,
*test_utils.py*,
*test_external_api.py*.
